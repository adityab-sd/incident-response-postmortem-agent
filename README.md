# Incident Response & Root Cause Post-Mortem Agent

> A DevOps triage pod that handles an active application alert from Slack/PagerDuty.

## Overview
An automated incident response and root-cause analysis pod designed to triage active application alerts, gather telemetry/logs, diagnose issues, and draft comprehensive post-mortem reports.

## Features
- **Alert Ingestion**: Listens to active alerts triggered via Slack and PagerDuty webhooks/events.
- **Diagnostics & Triage Pod**: Automatically fetches metrics, logs, traces, and service health status.
- **Root Cause Analysis (RCA)**: Pinpoints anomalies, correlated deployments, and faulty dependencies.
- **Automated Post-Mortem Generation**: Synthesizes incident timelines, remediation steps, and preventive action items.
